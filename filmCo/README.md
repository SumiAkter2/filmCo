## 🌐 API Used

- TVMaze API

### All Shows

- `https://api.tvmaze.com/shows`

### Search Shows

- `https://api.tvmaze.com/search/shows?q=QUERY`

### Example

- `https://api.tvmaze.com/search/shows?q=girls`

## 🔍 Search

- When the search box is empty, all shows are displayed.
- When the user searches for a show, matching shows are displayed.
- Search results are loaded from the TVMaze API.

## 🎬 Show Details

When the user clicks the **See Details** button:

- A details modal opens
- Large show poster is displayed
- Show title is displayed
- Rating is displayed
- Release date is displayed
- Genre is displayed
- Show summary is displayed
- Modal can be closed using the close button
